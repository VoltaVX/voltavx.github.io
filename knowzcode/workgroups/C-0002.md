# C-0002 — Glass styles and reusable UI rules

Primary intent: Apply an Apple Liquid Glass inspired web visual system to the existing scaffold and deliver it as a complete archive and a portable pack.
Classification: BEHAVIOR. Architecture version remains 1. User request authorizes this bounded implementation.

## Minimum change set
- src/styles/tokens.css, global.css: shared material, color, typography, geometry and accessibility preferences.
- src/styles/scaffold.css (new): adapter for C-0001 scoped visuals, imported by global.css. Same module and two layout imports.
- AGENTS.md, src/styles/AGENTS.md: comprehensive numerical rules and concise API/ownership contract.
- src/pages/system.astro: correct two type descriptions when display changes from Georgia to system sans; no structural change.
- instructions.md: paste-ready migration prompt, package map and rollback instructions.
- tests/browser/glass.spec.ts: meaningful visual/preference/reflow checks, temporary semantic fixture only.
- KnowzCode spec/tracker/log; .ai/state.json/handoff; docs/verification/C-0002.md; README link to rules and migration prompt.

## Plan and critique
1. Verify Apple, MDN and W3C primary guidance and current source/archive identity.
2. Preserve existing token names, five cascade layers, class names, source boundaries, routes, hosting and native interactions. No ADR required: no module/dependency/interface restructuring.
3. Write behavior checks; implement styles, then document all element spacing and exception rules.
4. Build/type/unit/browser validation at root and /preview/. Inspect desktop/mobile views; test portable pack against the previous archive, not only the updated repo.
5. Read-only review against the spec; fix only findings within scope. Record evidence, commit, bundle and package.

Risks: scoped CSS can override portable styles; the adapter must deliberately win specificity. Transparent colors require contrast against composites. Blur and preference support differ. Documentation must not misattribute project pixel values to Apple. Opaque fallbacks must preserve meaning.
Rollback: restore the previous entire styles folder and matching AGENTS.md guidance; revert C-0002 in Git. No data or hosting migration.
