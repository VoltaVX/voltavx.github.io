# C-0010 source review — 2026-10-18

Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) distinguishes interactive Liquid Glass from standard materials within content. Use effects sparingly, select material by semantic role and protect label contrast. Sidebar labels and annotations are content, so this project uses a restrained standard-material-inspired frosting instead of clear interactive glass. CSS cannot reproduce native lensing or automatic adaptive luminance. Existing preference fallbacks are mandatory.

Apple [Layout](https://developer.apple.com/design/human-interface-guidelines/layout) recommends adaptable layouts, respected margins, alignment and consistent spacing. It supplies no universal website section-gap value. [web.dev Spacing](https://web.dev/learn/css/spacing/) explains separate margin, padding and layout gap responsibilities; [responsive basics](https://web.dev/articles/responsive-web-design-basics) recommends fitting content to available widths rather than device-specific fixed canvases. Applied project decisions: one shared64–120px leading section gap, equal image gutters and no capped mobile portrait, content-sized callouts with growing tracks. Numbers are authored customizations, not official Apple measurements.

Original screenshots show left-aligned six-step text, a narrow About portrait, an opaque-looking discipline card and a cropped hero face. These motivate centered process text, full content-width About image, restrained frosting and upper-biased hero focal positioning. Source findings and browser acceptance are separate.
