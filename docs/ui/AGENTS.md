# UI specification ownership

Read [design.md](design.md), then the affected component specifications. This directory owns current reusable UI requirements. Keep requirements concrete: anatomy, exact spacing/type, states, responsive behavior, semantics and verification. Update manifest.json and the main coverage table with each new component spec. Do not change approved copy or global values without user scope authority. reference/ is historical evidence, not an alternate authority. No Markdown from this directory belongs under src/pages/.
