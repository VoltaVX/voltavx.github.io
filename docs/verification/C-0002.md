## Failure observations and bounded repairs

- The original unmodified scaffold fails the new glass navigation test with computed backdrop-filter:none. This confirms the behavior check detects the visual change.
- Review tests failed on hero spacing (32px instead of 24px) and long native button labels (internal width exceeded the control). Narrow repeated-class selectors repair the known C-0001 scoped cascade conflicts; overflow-wrap:anywhere repairs button labels.
- The initial transition test incorrectly expected one duration string; two zero durations are valid. The revised assertion verifies every duration is zero.
- Firefox represents 44px as 43.999996px; a 0.01px numerical tolerance handles this floating-point difference without accepting materially undersized controls.
- Text-spacing overrides now apply to all elements. Forced-color tests reset high contrast and verify the two media conditions independently.
- Temporary media fixtures await image decode and font readiness before geometry checks. A short fixture reflow check was repeated 10 times successfully during investigation.
- Visual inspection found a repeated background seam on a short route. A viewport-height body and no-repeat background repair it.

## Environment and reproduction

Use Node 24, npm ci, npm run check, npm test, npx playwright install, then npm run test:e2e. Repeat with SITE_URL=https://example.com BASE_PATH=/preview/.

The validation container required temporary browser binaries/library paths and a Firefox content-sandbox environment setting. These are outside the project and absent from the packages. A stale partial Chromium executable crashed; replacing the temporary binary restored tests. Project dependencies did not change. No lint command is configured.

## Limits

Automated axe checks do not certify WCAG conformance. Native adaptive Liquid Glass refraction is not implemented by CSS. Unsupported-blur fallback was reviewed structurally; no historical unsupported browser was available. Reduced-transparency OS propagation is not verified on Firefox/WebKit. Manual screen readers, physical devices, real browser UI zoom at 400%, low-powered-device blur performance and live GitHub deployment were not tested. The 320px reflow check covers an equivalent CSS layout width for 1280px at 400% zoom; it does not replace a real browser zoom check. Agent instructions do not guarantee model compliance.
